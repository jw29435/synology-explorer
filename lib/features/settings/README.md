# settings

App-Einstellungen (Screen 26): Server verwalten, Freigabelinks, Streaming nur WLAN, Auto-Upload, Wiedergabe,
Cache-Limit, Offline-Speicher, Design, Sprache, Über & Lizenzen, „Alle lokalen Daten löschen“.
Werte liegen als Schlüssel/Wert in der drift-Tabelle `settings` (`SettingsRepository`).
